# Arquivos privados locais

Guarde nesta pasta somente materiais que não devem ser enviados ao GitHub: respostas de formulários, contatos de interessados, credenciais, documentos recebidos e fotos ainda sem autorização de publicação.

O `.gitignore` da raiz ignora todos os arquivos desta pasta, exceto este README. Não colocar dados pessoais neste README nem em mensagens de commit. Quando houver fotos autorizadas para o site, coloque os originais aprovados em `src/assets/` para otimização no build do Astro e documente a autorização na base de conhecimento.

O `.gitignore` só impede que arquivos **ainda não rastreados** sejam adicionados normalmente. Se algum segredo já tiver sido commitado ou enviado ao GitHub, removê-lo do histórico e trocar a credencial antes de publicar o repositório.
